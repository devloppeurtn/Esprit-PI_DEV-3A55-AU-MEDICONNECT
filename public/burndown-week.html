Diagramme de sequence - Module 2 (planning, disponibilite, RDV, validation)

Fixation des plages horaires par la secretaire, prise de RDV par le patient selon disponibilite, validation, notification et visualisation des consultations. 
sequenceDiagram
  autonumber
  actor Secretaire
  actor Patient
  participant UI as Interface Web
  participant Planning as PlanningMedecin
  participant Dispo as DisponibiliteService
  participant RDVRepo as RendezVousRepository
  participant ConsultRepo as ConsultationRepository
  participant Notif as NotificationService
  participant DB as Database

  Secretaire->>UI: Ouvrir configuration planning
  UI->>Planning: Charger planning du medecin
  Planning->>DB: Lire planning existant
  DB-->>Planning: Donnees planning
  Planning-->>UI: Afficher formulaire planning
  Secretaire->>UI: Definir plages horaires + duree
  UI->>Planning: Enregistrer planning
  Planning->>DB: Persist planning
  DB-->>Planning: OK
  Planning-->>UI: Confirmation

  Patient->>UI: Ouvrir prise de RDV
  UI->>Dispo: Demander disponibilites(date, medecin)
  Dispo->>Planning: Lire planning
  Planning->>DB: Charger planning
  Dispo->>RDVRepo: Charger RDV existants
  RDVRepo->>DB: Lire RDV du medecin
  Dispo-->>UI: Creneaux libres/occupes
  Patient->>UI: Choisir creneau + soumettre
  UI->>RDVRepo: Creer RDV (statut EN_ATTENTE)
  RDVRepo->>DB: Insert RDV
  RDVRepo-->>UI: RDV en attente
  UI->>Notif: Notifier secretaire/medecin
  Notif-->>Secretaire: Notification nouvelle demande

  Secretaire->>UI: Valider ou refuser RDV
  UI->>RDVRepo: Mettre a jour statut
  RDVRepo->>DB: Update RDV
  RDVRepo-->>UI: Statut mis a jour
  UI->>Notif: Notifier patient
  Notif-->>Patient: RDV confirme/refuse

  UI->>ConsultRepo: Compter consultations pour tableau de bord
  ConsultRepo->>DB: Aggregation
  ConsultRepo-->>UI: Statistiques consultations
