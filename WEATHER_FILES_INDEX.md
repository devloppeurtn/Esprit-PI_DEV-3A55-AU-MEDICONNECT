## 🚀 Quick Actions

### Setup in 3 Steps
1. Get API key: https://openweathermap.org
2. Add to `.env.local`: `WEATHER_API_KEY=your_key`
3. Create event with location: `/evenement/nouveau`
4. View: `/evenement/{id}` → See weather! 🌤️

### View Documentation
```bash
# Open Quick Start
cat WEATHER_QUICK_START.md

# Open Setup Guide
cat WEATHER_SETUP.md

# Open Visual Guide

# All files
ls WEATHER_*.md
```

   - Location: "Paris, France"
   - Date: Today
