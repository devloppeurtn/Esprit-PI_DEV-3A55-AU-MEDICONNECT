═══════════════════════════════════════════════════════════════
🚀 COMMENT ÇA MARCHE ?
═══════════════════════════════════════════════════════════════

ÉTAPE 1 : PARTICIPER À UN ÉVÉNEMENT
────────────────────────────────────────────────────────────

1. Aller sur la page d'un événement
2. Cliquer sur "Participer"
3. Remplir le formulaire avec votre email
4. Attendre que l'événement soit terminé

ÉTAPE 2 : LAISSER UN FEEDBACK
────────────────────────────────────────────────────────────

1. Retourner sur la page de l'événement (après sa date)
2. Cliquer sur "Laisser un feedback"
3. Entrer l'email utilisé lors de l'inscription
4. Choisir une note (1-5 étoiles)
5. Laisser un commentaire (optionnel)
6. Soumettre

ÉTAPE 3 : VOIR LES FEEDBACKS
────────────────────────────────────────────────────────────

1. Sur la page de l'événement
2. La note moyenne est affichée avec des étoiles
3. Cliquer sur "Voir tous les feedbacks"
4. Page avec statistiques et tous les commentaires

═══════════════════════════════════════════════════════════════
🔧 DÉPANNAGE
═══════════════════════════════════════════════════════════════

PROBLÈME : Le bouton "Laisser un feedback" n'apparaît pas
SOLUTION :
• Vérifier que l'événement est terminé (date passée)
• L'événement doit être validé (statut VALIDE)

PROBLÈME : Erreur "Vous devez avoir participé à cet événement"
SOLUTION :
• Vérifier que l'email est correct
• Vérifier que vous êtes inscrit à l'événement
• L'email doit correspondre exactement

PROBLÈME : Impossible de modifier mon feedback
SOLUTION :
• Utiliser le même email que lors de la création
• Le système détecte automatiquement le feedback existant

📊 BASE DE DONNÉES
═══════════════════════════════════════════════════════════════

TABLE CRÉÉE : event_feedback

COLONNES :
• id : Identifiant unique
• participant_id : Référence au participant
• evenement_id : Référence à l'événement
• rating : Note de 1 à 5
• comment : Commentaire (optionnel)
• created_at : Date de création
• updated_at : Date de modification

CONTRAINTES :
• Un feedback par participant par événement
• Note entre 1 et 5
• Commentaire max 1000 caractères
